# سيرفر الملتيبلاير — سيف الأساطير (5×5 اونلاين)

الملفات دي **منفصلة تماماً** عن موقع اللعبة (اللي بينشر على Cloudflare Pages).
دي مشروع Cloudflare **Worker** لوحده، لازم يتنشر لوحده بأمر `wrangler`، وهيديك
رابط سيرفر تحطه جوه `index.html`.

## ✅ مجاني بالكامل
Durable Objects (اللي بتشغل غرفة الانتظار وغرف المعارك) بقت **متاحة على خطة
Cloudflare Workers المجانية بالكامل** من غير أي اشتراك — مش محتاج تدفع حاجة.
الحد المجاني تقريبًا 3 مليون طلب و~390 ألف GB-ثانية شهريًا، أكتر بكتير من
كفاية للعبة صغيرة.

الحاجة الوحيدة اللي لازم تنتبهلها: ملف `wrangler.toml` المرفق بيستخدم
`new_sqlite_classes` (مش `new_classes`) عشان يشتغل على الخطة المجانية —
ده متظبط بالفعل في الملف، مش محتاج تغيّر حاجة.

---

## 1) التجهيز
```bash
npm install -g wrangler
wrangler login
```
لما تعمل login، اختار **حساب مجاني (Free)** عادي — مش هيطلب منك بطاقة ائتمان
ولا اشتراك عشان تنشر الـ Worker ده.

## 2) النشر
من جوه مجلد `multiplayer-server`:
```bash
cd multiplayer-server
wrangler deploy
```
هيديك رابط زي:
```
https://sword-of-legends-mp.<اسمك-على-كلاودفلير>.workers.dev
```

## 3) ربط الرابط باللعبة
افتح `index.html` بتاع اللعبة، دور على السطر ده (قريب من بداية كود الملتيبلاير):
```js
var MP_SERVER_URL = 'wss://YOUR-WORKER-SUBDOMAIN.workers.dev';
```
غيّره للرابط اللي طلع لك، لكن لازم يبدأ بـ `wss://` بدل `https://` (لأنه
اتصال WebSocket آمن). مثال:
```js
var MP_SERVER_URL = 'wss://sword-of-legends-mp.ahmed.workers.dev';
```
ادفع التحديث لـ GitHub زي المعتاد، Cloudflare Pages هتنشره أوتوماتيك.

## 4) تجربة سريعة (بدون نشر اللعبة كلها)
بعد `wrangler deploy`، افتح الرابط في المتصفح — المفروض تشوف رسالة نصية
بسيطة تأكد إن السيرفر شغال. الاختبار الحقيقي للـ matchmaking يحتاج
جهازين (أو تابين) يدخلوا اللعبة ويضغطوا "🌐 اونلاين 5×5" في نفس الوقت
تقريباً.

## 5) إزاي شغال بالظبط
- `/queue` — أي لاعب بيتصل هنا وهو بيدور على ماتش. أول ما يتجمع لاعبين
  (لغاية 10) بيتوزعوا فريقين ويتبعتلهم رقم غرفة (`roomId`).
- `/room/{roomId}` — كل لاعبين الماتش بيتصلوا هنا؛ السيرفر بيبقى مجرد
  "مُرحِّل" (relay) بيوصل رسائلهم لبعض؛ منطق اللعبة (حركة/قتال/استيلاء
  على مناطق) شغال بالكامل جوه `index.html` على جهاز أول لاعب دخل
  الغرفة (يسمى الـ **host**)، والباقي بيبعتوا حركتهم بس ويستقبلوا حالة
  اللعبة الجاهزة منه.
- لو مفيش لاعبين حقيقيين كفاية خلال 20 ثانية، اللعبة بترجع تلقائي
  لوضع البوتات المحلي (زي زرار "معركة الدوري 5×5 (بوتات)").
- لو لاعب اتقطع نص المعركة، مكانه بيتحول تلقائي لبوت عشان الماتش يكمل.

## 6) حدود النسخة دي (v1) — تستحق التطوير لاحقاً
- الـ host هو اللي بيحسب كل الأضرار؛ لو حد شغل نسخة معدّلة من اللعبة
  كـ host يقدر يغش في **معركته هو بس** (مش بيانات حسابات لاعبين
  تانيين، دي محفوظة بشكل منفصل على كل جهاز).
- مفيش نظام "failover" لو الـ host فصل نص المعركة — المعركة بتنتهي
  بإشعار للاعبين الباقيين بدل ما تنقل الاستضافة للاعب تاني تلقائياً.
- مفيش تنعيم حركة (interpolation) لمواقع اللاعبين التانيين بين كل
  تحديث شبكة — ممكن تلاحظ حركتهم شوية "قافزة" على نت بطيء. تحسين
  بسيط لاحق: تخزين آخر موقعين واعمل lerp بينهم بدل النقل المباشر.
