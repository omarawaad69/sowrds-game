# سيف الأساطير — دليل الرفع والنشر

## الفكرة باختصار
الـ APK اللي هتعمله **مش هياخد نسخة من ملفات اللعبة جواه**. هو غلاف بسيط (Trusted Web
Activity) بيفتح رابط موقعك المنشور على Cloudflare Pages. يعني أي تحديث تعمله وترفعه على
GitHub → Cloudflare بينشره أوتوماتيك → أول ما حد يفتح التطبيق (وهو أونلاين) هيشوف
آخر نسخة على طول، من غير ما يمسح التطبيق أو ينزله تاني.

فيه كمان service worker (`sw.js`) بيخزن نسخة احتياطية عشان اللعبة تفتح حتى لو النت مقطوع،
لكنه بيحاول يجيب النسخة الجديدة من النت الأول (network-first) — فمفيش تعارض مع التحديث
التلقائي.

---

## 1) رفع الملفات على GitHub
1. اعمل repo جديد (مثلاً `sword-of-legends`).
2. ارفع الملفات دي زي ما هي في نفس المجلد الجذري للـ repo:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-512-maskable.png`
   - `_headers`
3. أي تحديث بعد كده = `git commit` + `git push` بس.

## 2) نشر على Cloudflare Pages
1. من لوحة Cloudflare → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. اختار الـ repo.
3. إعدادات البناء: مفيش build command (الموقع static)، وخليه ينشر من الـ root.
4. بعد أول نشر هتاخد رابط زي: `https://sword-of-legends.pages.dev`
   (تقدر تربط دومين خاص بيك بعدين من نفس اللوحة).
5. من هنا، أي `git push` جديد = نشر تلقائي خلال ثواني.

⚠️ **مهم:** غيّر كلمة سر المطور `ADMIN_PASSWORD` في `index.html` (دورها على
`Legend#2026`) لكلمة سرية خاصة بيك قبل ما تنشر الرابط لأي حد، عشان محدش يفتح لوحة
المطور غيرك.

## 🌐 الملتيبلاير الحقيقي (5×5 اونلاين)
اللعبة دلوقتي فيها وضعين لمعركة الـ 5×5:
- **معركة الدوري 5×5 (بوتات)** — زي ما كانت، محلية بالكامل.
- **اونلاين 5×5 (لاعبين حقيقيين)** — بتوصلك بلاعبين مسجلين فعليين، ولو
  العدد ماكملش بتكمل بالبوتات تلقائياً.

الوضع الاونلاين محتاج سيرفر منفصل (Cloudflare Worker) — **مجاني بالكامل**،
مش هتحتاج تدفع أي اشتراك. التفاصيل والخطوات كاملة في
`multiplayer-server/README.md`. من غير ما تنشره وتحط رابطه في
`index.html`، زرار "اونلاين 5×5" هيقولك إنك محتاج تنشره الأول.


## 3) عمل APK من الرابط (Trusted Web Activity)
أسهل طريقة من غير برمجة Android هي موقع **PWABuilder**:

1. روح على https://www.pwabuilder.com
2. حط رابط الموقع بتاعك على Cloudflare Pages (مثلاً
   `https://sword-of-legends.pages.dev`) واضغط Start.
3. PWABuilder هيقرأ الـ `manifest.webmanifest` والـ `sw.js` تلقائي ويقيّم اللعبة.
4. من تبويب **Android** اختار **Generate Package** → **Trusted Web Activity (TWA)**.
5. هيديك ملف `.aab` أو `.apk` للتحميل، ومعاه ملف `assetlinks.json`.
6. ارفع `assetlinks.json` في `.well-known/assetlinks.json` على نفس الدومين
   (Cloudflare Pages) — ده اللي بيأكد إن التطبيق فعلاً بتاعك وبيشيل شريط
   المتصفح من فوق فيبقى شكله زي تطبيق حقيقي 100%.
7. ثبّت الـ APK على أي جهاز أندرويد للتجربة، أو ارفعه على Google Play.

## 4) بعد كده، أي تحديث؟
بس عدّل `index.html` (آيتمز جديدة، أعداء جدد، أي حاجة) وابعتها GitHub:
```
git add .
git commit -m "تحديث اللعبة"
git push
```
Cloudflare هينشرها لوحده، والتطبيق المثبت عند اللاعبين هيجيبها أول ما حد يفتحه
وهو متصل بالنت — **من غير أي حذف أو تنزيل تاني**.

لو حبيت تتأكد إن كل اللاعبين اتحدّثوا فوراً وميستناش يقفلوا التطبيق ويفتحوه تاني،
ده بيحصل تلقائي كمان: الكود جوه `index.html` فيه كود بيكتشف أول ما نسخة جديدة تتفعل
جوه الـ service worker وبيعمل ريفريش لصفحة اللعبة لوحده.
